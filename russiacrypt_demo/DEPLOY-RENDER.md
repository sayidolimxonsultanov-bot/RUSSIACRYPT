# Публикация RUSSIACRYPT как демо-сайта

## Перед публикацией

Этот проект — только учебный симулятор. RUCOIN и EUR виртуальные; реальных платежей и выплат нет. Не собирайте реальные персональные данные и не используйте этот проект как финансовый сервис.

## Самый простой бесплатный тестовый запуск через Render

1. Войдите в GitHub и создайте **пустой приватный репозиторий** с названием `russiacrypt-demo`.
2. На странице репозитория нажмите **Add file → Upload files**, загрузите содержимое этой папки (включая `render.yaml` и `.gitignore`), затем нажмите **Commit changes**. Не загружайте `russiacrypt.db`, `.env` или пароли.
3. Откройте Render Dashboard, выберите **New → Blueprint** и подключите этот GitHub-репозиторий.
4. Render обнаружит `render.yaml`. Подтвердите создание сервиса.
5. После успешного Deploy откройте адрес `https://...onrender.com`, показанный в панели Render.

## Важное ограничение бесплатного тарифа

Render Free отключает простаивающие сервисы, а локальные файлы бесплатного web-сервиса не сохраняются после сна/перезапуска/нового deploy. Поэтому SQLite-база, демо-аккаунты, тестовые балансы и история могут сброситься. Используйте этот способ только для показа интерфейса. Для сохранения аккаунтов потребуется постоянное хранилище или внешняя база данных и отдельная настройка приложения.

## Пароль администратора

При первом старте сервер создаёт администратора `owner` и генерирует пароль, если переменная `ADMIN_PASSWORD` не задана. Найдите его в логах первого запуска сервиса и сохраните в безопасном месте. Не отправляйте пароль в чат и не публикуйте его в GitHub. Если задаёте `ADMIN_PASSWORD` в Render Environment, используйте длинный уникальный пароль и не используйте его ни на одном другом сайте.

## Если не публикуется

Проверьте в Render: Deploys → Logs. Убедитесь, что сервис прочитал `render.yaml`, а команды сборки и запуска завершились успешно.
