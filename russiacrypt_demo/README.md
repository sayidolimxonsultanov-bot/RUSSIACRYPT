# RUSSIACRYPT — демонстрационный веб-сайт

Это учебный симулятор интерфейса криптоплатформы, который можно развернуть как публичную демо-страницу. В нём есть регистрация и вход, портфель, фиксированная условная цена RUCOIN (€150), демо-покупка и продажа, пополнение тестового баланса, имитация вывода, история операций и серверная админ-панель.

**Важно:** RUCOIN не является настоящей криптовалютой. EUR и RUCOIN — только тестовые единицы внутри локального приложения. Не подключены банковские карты, платёжные сервисы, криптобиржи, блокчейн или реальные выплаты. Не используйте этот прототип для приёма денег или предложения инвестиций.

## Запуск на Windows

1. Установите Python 3.10 или новее.
2. Распакуйте архив в отдельную папку.
3. Запустите `start.bat` (или откройте терминал в папке и выполните `python server.py`).
4. При первом запуске сервер выведет в окно консоли логин администратора и автоматически сгенерированный пароль. Сохраните пароль: повторно он не показывается.
5. Откройте `http://127.0.0.1:8080` в браузере.
6. Обычные пользователи могут создать аккаунт через вкладку «Регистрация».

## Запуск на macOS / Linux

В терминале из папки проекта выполните:

```bash
python3 server.py
```

Затем откройте `http://127.0.0.1:8080`.

## Админ-панель

Первый аккаунт, созданный сервером, получает роль администратора. По умолчанию логин — `owner`, пароль генерируется случайно и печатается в консоль при первом старте. Администратор может просматривать зарегистрированные демо-аккаунты и корректировать их виртуальные балансы EUR и RUCOIN. Все корректировки записываются в журнал операций.

При необходимости задать логин и пароль до первого запуска на Windows PowerShell:

```powershell
$env:ADMIN_USERNAME = "owner"
$env:ADMIN_PASSWORD = "replace-with-a-long-demo-password"
python server.py
```

Эти переменные применяются только при создании первого администратора. Если файл `russiacrypt.db` уже создан, удалите его только для полного сброса тестовой базы и повторного создания администратора.

## Правило демо-вывода

Форма принимает тестовые заявки ежедневно с 16:30 до 16:59 по московскому времени. Лимит — до 20% от демонстрационного EUR-баланса на начало соответствующего часа. Баланс меняется только внутри локальной тестовой базы; никакой внешний перевод не выполняется.

## Публичное демо

Для тестового размещения используется `render.yaml`. Публичная демо-версия не предназначена для реальных денег, сбора реальных персональных данных или постоянного хранения аккаунтов. На бесплатном хостинге Render файловая система временная: SQLite-база и зарегистрированные аккаунты могут исчезать после перезапуска, сна или повторного развёртывания. Для постоянных данных потребуется отдельная настроенная база данных и дополнительная проверка безопасности.

## Данные и безопасность

- Данные хранятся в файле `russiacrypt.db` в папке проекта.
- Пароли хранятся в виде PBKDF2-HMAC-SHA256-хеша с индивидуальной солью.
- Сессии и проверка роли администратора обрабатываются сервером.
- Локально сервер по умолчанию слушает `127.0.0.1`; для хостинга `render.yaml` задаёт `HOST=0.0.0.0` и защищённый флаг cookie.
- Это публичная демонстрация учебного симулятора, а не готовый финансовый сервис. Не принимайте деньги, не обещайте доходность и не используйте реальные пароли или личные данные пользователей.

## Структура проекта

- `server.py` — HTTP-сервер, SQLite, регистрация, сессии, торговая симуляция и admin API.
- `index.html` — интерфейс сайта.
- `style.css` — оформление.
- `app.js` — логика интерфейса.
